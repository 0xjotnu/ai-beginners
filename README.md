## 🌟 What is this?

This is a hands-on learning path for using, understanding, and building with modern AI. Start with the fundamentals, learn to communicate clearly with AI, then move into coding assistants, agents, creative tools, and automations.

The original Claude prompting guide is preserved as the first complete module. Its useful lessons are now framed around habits that transfer across leading AI tools.

> 🛠️ **Work in progress:** the foundation is ready and new modules are being added one by one. Contributions are welcome.

## ⚡ Start in 30 minutes

1. 📖 Read [What is AI?](01-ai-foundations/01-what-is-ai.md).
2. 🔍 Read [How language models work](01-ai-foundations/02-how-llms-work.md).
3. 🧰 Use [the tool guide](02-ai-tools/README.md) to choose one tool for a real task.
4. ✍️ Complete the five lessons in [Prompting](03-prompt-engineering/README.md).
5. 🧪 Adapt a worked [example](examples/) to something you need to do this week.

> The goal is not to memorize AI jargon. It is to try one useful task, check the result, and get a little better each time.

## 🧠 The five rules we return to

1. **🎯 Be clear about the outcome.** Say who the result is for and what “good” looks like.
2. **🧰 Use the right tool for the job.** A tool’s popularity matters less than fit, privacy, and verifiable output.
3. **🔎 Check important work.** AI can sound certain and still be wrong—verify facts, calculations, sources, and code.
4. **🔒 Protect private information.** Do not paste sensitive personal, company, or customer data into an unapproved tool.
5. **🌱 Build judgment, not dependence.** AI is a collaborator and accelerator, not an authority.
