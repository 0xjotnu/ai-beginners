# Reasoning, Checking, and Iteration

Some tasks require multiple steps, trade-offs, calculations, or careful judgment. For these, the best habit is not to demand hidden reasoning; it is to ask for a clear, checkable work product.

## Ask for useful intermediate outputs

For a difficult task, request the assumptions, a short plan, the calculation or evidence, and a final answer. For example:

```text
Compare these three options for a small team.

First list the criteria and any assumptions you are making.
Then make a comparison table with evidence for each claim.
Finally recommend one option and state what I should verify before deciding.
```

This makes gaps visible without requiring the model to reveal private internal reasoning.

## Verify by risk

- **Low risk:** revise tone, brainstorm ideas, or summarize text you already know.
- **Medium risk:** check facts, links, calculations, and code before use.
- **High risk:** use qualified human review for medical, legal, financial, security, employment, or consequential decisions.

## Iterate on the input

If a response misses the point, improve the prompt: add context, define the audience, show an example, or clarify the output format. Do not assume a polished answer is automatically correct.
