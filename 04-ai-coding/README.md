AI coding assistants can explain unfamiliar code, suggest changes, write tests, and help you debug. They do not replace understanding, version control, or verification. Think of one as a fast pair programmer: useful when you give it context and review its work.

## ✨ Your coding loop

```text
🎯 Define one small outcome → 🧩 Give relevant context → 🔨 Ask for the
smallest useful change → 🧪 Run tests → 🔎 Review the diff → 📌 Commit
```

## 🔒 Non-negotiables

- Never paste passwords, API keys, private customer data, or production secrets into a chat.
- Read and run code before you trust it — especially install commands, database changes, and security-related code.
- Keep changes small. A small diff is easier to understand, test, revert, and learn from.
- Use Git checkpoints. AI can make mistakes quickly; version control lets you recover quickly.
