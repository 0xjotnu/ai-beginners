# 4. Reasoning, Checking, and Iteration

For multi-step tasks, calculations, trade-offs, and judgment calls, ask for a clear work product you can inspect — rather than relying on a confident answer alone.

## Request useful intermediate outputs

Ask the model to state assumptions, give a short plan, show evidence or calculations where useful, and then provide a final recommendation. This makes gaps visible and lets you correct the task before acting on the result.

```text
Compare these three options for a small team.

First list the criteria and assumptions you are using.
Then make a comparison table with evidence for each claim.
Finally recommend one option and tell me what I should verify before deciding.
```

## Verify by risk

- For low-risk writing or brainstorming, review the result for fit and tone.
- For facts, calculations, links, and code, check the relevant evidence before use.
- For medical, legal, financial, security, or other high-impact decisions, use qualified human review.

## Iterate on the prompt

If the result misses the point, improve the input: add context, clarify the audience, show an example, or specify the output format. A polished response is not automatically a correct one.
