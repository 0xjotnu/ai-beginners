# 02 · AI Tools

Do not choose a tool because it is popular; choose it because it fits the task, your privacy requirements, and the way you work.

## Tool categories

| Need | Typical tool category | What to check |
| --- | --- | --- |
| Drafting, learning, brainstorming | Chat assistant | Quality, file support, privacy settings |
| Finding current information | Research/search assistant | Sources, dates, and whether citations open |
| Writing or reviewing code | Coding assistant | Editor integration, tests, repository access |
| Making images, audio, or video | Creative generator | Rights, editing controls, output quality |
| Repeating a workflow | Automation platform | Permissions, error handling, human approval |

## A simple choice process

1. Define the job in one sentence.
2. Decide whether the task needs current web information, private files, code access, or media generation.
3. Read the tool’s privacy and data-use settings before sharing anything sensitive.
4. Test the same small task in one or two tools and compare the output.
5. Keep the tool that gives you the best verified result with the least friction.

## Avoid tool wars

ChatGPT, Claude, Gemini, Copilot, Cursor, Perplexity, and other products change quickly. Learn transferable habits: clear instructions, source checking, structured outputs, version control, and good judgment. Those outlast any comparison chart.
